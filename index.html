01 / LLM built from scratch

musicGPT

Jul 2026 · Python · PyTorch · NumPy · tiktoken · pytest

A 45M-parameter GPT built from scratch in PyTorch (attention, RoPE, training loop, all hand-written), pretrained on ~1 billion Wikipedia tokens on a single GPU to write fluent, music-literate prose.

Code Training results
  • Implemented a decoder-only transformer (44.6M parameters — 6 layers, 8 heads, 512-dim) with every core component written by hand: multi-head causal self-attention, rotary positional embeddings (RoPE), LayerNorm with fp32 statistics, and GPT-style weight init — no pre-built transformer layers.
  • Engineered a streaming data pipeline that pulls official Wikipedia dumps over HTTP, strips nested wiki markup with a hand-rolled parser, and packs 0.92B GPT-2 BPE tokens into memory-mapped binaries — upweighting music articles 3× for domain fluency.
  • Trained at the compute-optimal ~20 tokens-per-parameter budget on a single L4 GPU with mixed precision, cosine LR scheduling, and gradient accumulation — sustaining ~90k tokens/sec and reaching validation perplexity ≈ 26 with train and val loss tracking tightly (3.24 / 3.26): no overfitting.
  • Built an 11-test pytest suite: manual-attention vs. fused-kernel equivalence, causality, RoPE rotation geometry, and an init-loss sanity check that caught a real weight-tying bug during development.
